# Brand guidelines

Soft Harmony: calm, elegant, modern, premium. Light flagship; coherent optional dark theme. Original geometric orbit mark to be designed. No assets created yet. Verify name availability before publication.

Warm ivory #F8F7F3; pearl #FFFFFF; sage mist #E8EFE9; muted sage #729A89; primary action deep sage #416B59; powder blue #DCE8F1; lavender #EDE4F2; peach #F3E5D9; charcoal #293631; secondary text #596861; border #E4E9E3. Success #3F785C, warning #966B3D, error #A94747.

Pastels support surfaces, not low-contrast text. Validate actual text/control combinations before acceptance. Tasks sage, goals lavender, habits peach, calendar blue. Avoid decorative clutter, heavy shadows and excessive motion.

Inter preferred only with verified bundled license; platform fallback until font distribution is resolved. Launcher, splash, in-app mark and empty-state assets remain unimplemented.

Original vector brand assets now implemented in src/ui/Icon.tsx and Android drawable/orbia_mark.xml, with adaptive launcher resources for API 26+ and Android 12+ splash styling. Template launcher fallbacks on API 24–25 remain a release limitation. Trademark/store-name checks still required. No third-party image or font assets added.
